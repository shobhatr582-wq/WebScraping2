# Books to Scrape Pagination Web Scraper

## Project Overview
This project demonstrates web scraping with pagination using Python. It scrapes book titles and prices from the Books to Scrape website by following the "Next" button across multiple pages.

## Technologies Used
- Python
- Requests
- BeautifulSoup (bs4)
- CSV

## Features
- Sends HTTP requests to the website.
- Parses HTML using BeautifulSoup.
- Extracts book titles and prices.
- Handles pagination using the Next button.
- Saves scraped data to a CSV file.

## Output
The scraped data is saved in a file named:

books.csv
